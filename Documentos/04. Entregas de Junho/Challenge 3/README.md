# Desafio 3 - Testes de Qualidade de Software

Este diretório contém os artefatos relacionados aos testes da API Serverest, desenvolvidos como parte do Desafio 3.

## Conteúdo

* **Testes Postman (json):** Contém os testes manuais realizados na API Serverest utilizando o Postman.
* **testes_robot_refatorado:** Inclui os testes refatorados desenvolvidos com Robot Framework, que são candidatos para a automação da API Serverest.
* **Planejamento de Teste - ServeREST.pdf:** Apresenta o planejamento de testes para a API Serverest.

## Próximos Passos

* Evoluir a automação dos testes da API Serverest utilizando Python/Pytest.
* Incluir no planejamento de testes (PDF) a seção sobre a configuração da API Serverest e a execução de testes automatizados em máquinas virtuais.
* Vincular bugs nos Test Cases (Jira).
